# 版本发布说明生成器

从技术性的 CHANGELOG.md 提取核心新特性，生成简洁、易懂的版本发布说明文档。

## 执行步骤

1. **读取 CHANGELOG.md**
   - 定位到指定版本的变更记录
   - 如果用户未指定版本，使用最新版本

2. **分析和提取核心特性**
   从 Added 部分识别重点新特性：
   - 新增的重要组件（如网络、音视频、USB等）
   - 新增的协议支持（如RTSP、HTTPs DNS等）
   - 新增的硬件接口（如I2S、4G模组等）
   - 重要的功能增强（如实时音量调节等）

   筛选标准：
   - 优先选择用户可感知的功能
   - 关注底层能力的重大提升
   - 每个版本控制在 4-8 个核心特性

3. **生成发布说明**
   使用扁平化纯文本格式，风格活泼友好：
   ```
   ARCS SDK vX.X.X 发布啦[庆祝][庆祝]

   ✨ 重点新特性

   1. 特性标题
      一句话描述特性的功能和价值

   2. 特性标题
      一句话描述特性的功能和价值

   ————————————————————————

   发布代码仓库：
   [仓库链接]

   更多升级内容详见：
   [CHANGELOG链接]
   ```

4. **格式规范**
   - **标题风格**：使用"ARCS SDK vX.X.X 发布啦[庆祝][庆祝]"，营造发布氛围
   - **章节标记**：使用"✨ 重点新特性"，添加表情符号增强视觉效果
   - **扁平化序号**：特性使用连续数字序号（1、2、3...），不使用二级序号（1.1、1.2）
   - **描述缩进**：特性描述缩进3个空格，与序号对齐
   - **空行分隔**：每个特性之间保留一个空行
   - **分隔线**：使用"————————————————————————"（24个横线）分隔内容和链接
   - **链接换行**：标签与链接分两行显示
   - **链接文案**："更多升级内容详见："替代"完整技术变更详见："，更口语化

5. **内容要求**
   - **简洁第一**：每个特性标题+描述，总字数不超过40字
   - **无技术术语**：避免代码级别的细节描述（除非是特性名称本身）
   - **友好风格**：标题和章节可以使用表情符号（[庆祝]、✨），增强亲和力
   - **无场景说明**：不添加"适用于XXX"等场景描述
   - **直接价值**：说明能做什么，不解释为什么

6. **交互流程**
   - 询问用户版本号（如果未指定）
   - 显示生成的发布说明
   - 询问是否保存为 RELEASE_NOTES_vX.X.X.md
   - 询问是否需要调整内容（增删特性）

## 示例输出

```
ARCS SDK v0.1.3 发布啦[庆祝][庆祝]

✨ 重点新特性

1. 4G网络支持
   支持4G模组接入，实现蜂窝网络连接和WiFi/4G自动切换

2. RTSP视频流
   支持RTSP协议，可用于网络摄像头、视频监控等场景的图传

3. HTTPs DNS解析
   支持HTTPs DNS，有效解决DNS劫持问题，提升网络连接成功率

4. I2S音频接口
   新增I2S驱动支持，可连接外部音频编解码芯片

5. 实时音量调节
   音频播放支持动态调节音量，提升用户体验

6. USB主机模式
   支持USB Host功能，可连接U盘、键盘等外设

————————————————————————

发布代码仓库：
https://cloud.listenai.com/CSKG836746/arcs-sdk/public/arcs-sdk/-/tree/release/v0.1.3

更多升级内容详见：
https://docs2.listenai.com/arcs-sdk/v0.1.3/zh/html/CHANGELOG.html
```

## 注意事项

- **必须**使用"发布啦[庆祝][庆祝]"的标题风格
- **必须**使用"✨ 重点新特性"的章节标记
- **必须**使用24个横线"————————————————————————"作为分隔线
- **必须**使用"更多升级内容详见："而非"完整技术变更详见："
- **不要**添加"适用场景"或"典型应用"部分
- **不要**使用技术术语（如API、驱动、组件等），除非是特性名称本身
- **不要**使用 Markdown 格式标记（#、##、### 等）
- **不要**使用二级序号（1.1、1.2），使用扁平化连续序号（1、2、3）
- **保持**活泼友好的风格，同时保持专业性
- **控制**篇幅在30行以内
- **不要**自动 git commit，让用户决定是否提交

## 版本号和链接

- 发布代码仓库链接格式：`https://cloud.listenai.com/CSKG836746/arcs-sdk/public/arcs-sdk/-/tree/release/vX.X.X`
- 完整技术变更链接格式：`https://docs2.listenai.com/arcs-sdk/vX.X.X/zh/html/CHANGELOG.html`
- 如果用户提供了其他链接，使用用户提供的链接
