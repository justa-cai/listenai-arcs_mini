# ARCS SDK概述

## 目录结构
```
arcs-sdk/
├── boards/                            ← 板级文件
├── soc/                               ← soc相关文件                             
├── startup/                           ← 系统启动相关初始化
├── drivers/                           ← 驱动文件 
├── cmake/                             ← CMake构建扩展 
├── components/                        ← 自研软件库
├── modules/                           ← 第三方开源库 
├── tools/                             ← 开发工具集
├── samples/                           ← 示例代码 
├── tests/                             ← 测试代码
├── docs/                              ← 完整文档 
├── README.md                          ← 说明文档
├── VERSION                            ← 版本信息
├── LICENSE                            ← 开源许可证
```
