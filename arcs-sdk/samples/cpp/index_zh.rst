C++ 示例
========

本节提供 C++ 语言特性使用示例，展示如何在 ARCS SDK 中使用 C++ 进行开发，包括 C++11 新特性、标准库容器、IO 流、正则表达式和多线程编程等。

这些示例演示了 C++ 在嵌入式系统开发中的应用，帮助开发者理解如何在资源受限的环境中高效使用 C++ 特性。
