# Tuner 镜像烧录地址说明

| 名称            | 烧录地址     | 备注                                                         |
|:------------- |:-------- |:---------------------------------------------------------- |
| boot.bin        | 0x000000  | BOOT固件,烧录到FLASH上,地址为基于0x30000000的偏移地址                      |
| ap.bin          | 0x200000  | AP固件,烧录到FLASH上,地址为基于0x30000000的偏移地址                        |
| arcs.bin        | 0x830000  | CP固件,烧录到FLASH上,地址为基于0x30000000的偏移地址                        |
