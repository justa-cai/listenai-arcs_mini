# FreeType 示例项目

这是一个演示如何使用 FreeType 库的示例项目。该示例展示了以下功能：

1. FreeType 库的初始化
2. 从内存中加载字体文件
3. 设置字体大小和设备分辨率
4. 渲染和显示字符位图

## 前置条件

1. 确保已启用 FreeType 模块：
   ```
   CONFIG_SDK_MODULE_FREETYPE=y
   ```

2. 示例使用内置的 data/As.I.Lay.Dying 字体文件，无需额外配置

## 构建和运行

1. 确保 prj.conf 中的配置正确
2. 运行构建脚本：
   ```bash
   ./build.sh
   ```

## 功能说明

1. 初始化串口（UART0，波特率115200）用于日志输出
2. 从内存加载内置字体文件
3. 设置字符大小（16点，300 DPI）
4. 依次渲染并显示字符'A'到'D'，对每个字符：
   - 显示字符度量信息（宽度、高度、bearingX、bearingY、advance）
   - 使用ASCII字符('#'和空格)打印字符位图

## 输出说明

程序运行后会输出以下信息：
1. FreeType 库初始化状态
2. 字体加载状态
3. 每个字符（A-D）的：
   - 度量信息（像素单位）
   - ASCII艺术形式的位图表示

## 注意事项

1. 示例使用内置字体文件，无需额外配置字体路径
2. 字符大小设置为16点，设备分辨率为300 DPI
3. 位图输出使用ASCII字符进行可视化展示
