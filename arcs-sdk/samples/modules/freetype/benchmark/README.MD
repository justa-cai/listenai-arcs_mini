# FreeType 性能基准测试

这是一个用于测试 FreeType 库各种操作性能的基准测试工具。通过这个工具，我们可以评估不同场景下 FreeType 的性能表现，帮助开发者选择最优的配置和使用方式。

## 测试场景

### 1. 单字符加载测试
- 测试不同字体大小（12, 16, 24, 32）下的字符加载性能
- 包含字母和数字的测试
- 测量加载时间和内存使用

### 2. 批量字符加载测试
- 测试不同长度文本的加载性能
- 测试用例：
  - 短文本："Hello"
  - 中等文本："Hello, World!"
  - 长文本："The quick brown fox jumps over the lazy dog"

### 3. 渲染性能测试
测试不同渲染配置的性能：
- 默认配置
- 无微调
- 强制自动微调
- 轻量级目标

### 4. 字形缓存性能测试
- 测试重复加载相同字符的性能
- 不同迭代次数（1, 10, 100）
- 评估 FreeType 内部缓存机制的效率

### 5. 字形变换测试
测试各种变换操作的性能：
- 旋转（45度）
- 水平拉伸（2倍）
- 垂直拉伸（2倍）
- 倾斜变换

### 6. 渲染模式测试
评估不同渲染模式的性能：
- 普通（抗锯齿）
- 轻量级
- 单色
- LCD（水平RGB）
- LCD（垂直RGB）

### 7. 轮廓提取测试
- 测试不同大小字符的轮廓提取性能
- 测试字体大小：12, 24, 48, 72
- 测试字符：'A', 'B', '@', '8'

## 输出格式

测试结果以表格形式展示，包含以下信息：
- 测试名称
- 执行时间（毫秒）
- 内存使用（字节）

## 使用方法

1. 在工程根目录下编译项目：
   ```bash
   ./build.sh
   ```

2. 编译完成后，可以在串口工具中查看测试结果输出

## 注意事项

- 所有测试使用内置字体数据
- 测试结果可能因系统性能和配置而异
- 内存使用统计功能需要系统支持
