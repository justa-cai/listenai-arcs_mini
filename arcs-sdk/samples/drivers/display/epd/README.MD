# UC8253c 墨水屏显示示例

该示例演示如何使用 UC8253c 墨水屏驱动，展示多种显示图案和刷新模式。

## 功能特性

- **多种显示图案**: 全白、全黑、棋盘格、水平条纹、垂直条纹、边框
- **智能刷新策略**: 自动在GC全刷和DU局刷之间切换
- **1bpp单色格式**: 优化的墨水屏显示格式
- **循环演示**: 自动切换不同图案进行演示

## 硬件接口说明

| 引脚名称 | 引脚号 | 功能描述 |
| --- | --- | --- |
| EPD_RST | PA01 | 硬件复位信号 |
| EPD_BUSY | PB04 | 忙状态检测 |
| EPD_CS | PB05 | SPI片选信号 |
| EPD_DC | PB00 | 数据/命令选择 |
| EPD_CLK | PB03 | SPI时钟信号 |
| EPD_MOSI | PDB01 | SPI数据输出 |

## 显示规格

- **分辨率**: 240 × 416 像素
- **颜色**: 黑白单色 (1bpp)
- **刷新模式**: GC全刷 + DU局刷
- **接口**: 4线SPI
- **驱动IC**: UC8253c

## 示例运行效果

程序启动后会循环显示以下图案：
1. 全白屏幕
2. 全黑屏幕  
3. 8×8棋盘格
4. 水平条纹
5. 垂直条纹
6. 边框图案

每个图案显示5秒后自动切换到下一个图案。
