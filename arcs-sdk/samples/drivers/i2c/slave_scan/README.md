# I2C 从设备地址扫描示例

## 简介

本示例演示了如何使用 I2C 驱动程序扫描 I2C 总线，并查找所有连接的从设备及其地址。

## 功能描述

程序初始化开发板上的 I2C0 控制器，并将其配置为主机模式。随后，程序会遍历所有可能的 7 位 I2C 地址（从 `0x01` 到 `0x7F`）。对于每一个地址，它会尝试发起一次通信。如果总线上有从设备在对应的地址上响应了应答信号（ACK），程序就会认为在该地址上找到了一个设备，并打印出该设备的十六进制地址。

整个扫描过程完成后，程序会打印一条结束信息，并关闭 I2C 控制器以释放资源。

## 硬件连接

要运行此示例，你需要将一个或多个 I2C 从设备连接到开发板的 I2C0 接口上。

-   **I2C0 SCL**: 连接到 `GPIO A23`
-   **I2C0 SDA**: 连接到 `GPIO A22`

请确保你的从设备与开发板共地。

## 编译和烧录

请参考项目根目录下的说明文档来编译和烧录固件到你的开发板。

## 预期输出

当程序运行时，你将通过串口终端看到类似以下的输出。具体打印出的地址取决于你实际连接的 I2C 从设备。

```text
Start scanning I2C bus...
Found I2C device at address: 0x5A
Found I2C device at address: 0x68
I2C bus scan finished.
```

如果没有任何设备被找到，则只会输出扫描开始和结束的消息。
