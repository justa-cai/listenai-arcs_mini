# 小应用测试集

通过几个可直接体验的小应用，检查固件的基本运行能力。01–04 无需云端服务；05 需要访问公开 HTTP 测试服务，06 需要设备云端 TTS 服务。

## 用例与 API 覆盖

| 用例 | 最低 API | 主要覆盖 API | 检查内容 |
| --- | --- | --- | --- |
| [01 贪吃蛇](01-snake.lua) | 3 | `screen.*`、`on_tick`、`on_button_click`、`storage.load/save` | 绘制、移动、转向、最高分存档 |
| [02 时钟](02-clock.lua) | 3 | `clock.now/localtime`、`screen.*` | 真实时间、校时后自动刷新 |
| [03 秒表](03-stopwatch.lua) | 3 | `clock.now`、`on_tick`、`on_button_click`、`buzzer.play` | 秒级计时、单击/双击、提示音 |
| [04 状态灯](04-status-led.lua) | 2 | `led.on/off/blink`、`on_button_click`、`on_exit` | 灯光切换、闪烁、退出清理 |
| [05 HTTP 与 JSON](05-http-json.lua) | 4 | `http.*`、`json.*`、`on_http_response` | 请求、解析、取消、错误及额度边界 |
| [06 应用内 TTS](06-tts.lua) | 4 | `tts.*`、`on_tts_result` | 播报、繁忙、连续播报及取消 |

面向带屏幕和功能键的设备，屏幕至少 200×200。完整接口见 [小应用文档](../../docs/miniapp.md)。

## 运行

在仓库根目录执行下方对应命令，上传后立即运行。
一次测一个；新上传的应用会替换当前应用。**长按功能键 3 秒退出。**

## 玩法与检查要点

### 01 贪吃蛇

```sh
adb push tests/miniapp/01-snake.lua /miniapp/
```

单击开始，之后单击顺时针转向，结束后单击重来。

- 开始后不操作：前进 3 格吃到食物、得 1 分，继续向前撞墙结束。
- 确认移动、转向和碰撞正常。
- 看到“最高分已保存”后，以相同文件名重新上传，确认最高分恢复。
  存档需要设备已校时；保存失败会在画面提示。

### 02 时钟

```sh
adb push tests/miniapp/02-clock.lua /miniapp/
```

与手机对照日期、时间和时区，观察一分钟是否正常走时。
未校时时应显示等待，校时后自动显示；闹钟结束后应显示当前时间。

### 03 秒表

```sh
adb push tests/miniapp/03-stopwatch.lua /miniapp/
```

单击立即开始/暂停/继续，快速双击清零并暂停；每次操作有提示音。

- 运行 10 秒、暂停 3 秒、再运行 5 秒，累计应约 15 秒。
- 双击后归零并保持暂停。
- 从设备时钟计时，以 `00:00`（分:秒）显示，每次 tick 检查并刷新；未校时需先等待。
- 与手机秒表对照 60 秒，允许约 1 秒的取整误差，不应持续变慢。每段开始/暂停都会取整，系统校时也会影响结果。
- 闹钟期间继续计时，返回小应用后显示更新的秒数。
- 在无 TTS/闹钟播放、音量非零时检查声音。

### 04 状态灯

```sh
adb push tests/miniapp/04-status-led.lua /miniapp/
```

单击依次切换：熄灭 → 常亮 → 慢闪 → 快闪 → 熄灭。

观察实体灯：慢闪亮 500 / 灭 500 ms，快闪亮 100 / 灭 900 ms。
退出或切换应用后，应结束小应用灯效。

---

测试时记录固件版本和异常现象。模拟器可检查脚本与画面，实体按键、声音和灯光需真机确认。

### 05 HTTP 与 JSON（API 4）

使用公开的 [httpbingo.org](https://httpbingo.org/) 测试接口，无需启动本地服务、修改局域网地址或配置密钥。设备联网后执行：

```sh
adb push tests/miniapp/05-http-json.lua /miniapp/
```

启动后自动依次检查 GET、嵌套 JSON/null、2 KiB POST、404、302 不跟随跳转、
响应大小超限、超时和流式响应。正常应显示“全部通过”，单击可以重跑。
启动时还检查取消幂等和启动请求 ID。对端服务不可达或任何断言失败均会退出并记录 Lua 错误。
公开服务或网络不可用时也会失败，应结合设备日志区分网络问题和固件缺陷；通过测试不代表验证了 TLS 证书校验。

### 06 应用内 TTS（API 4）

```sh
adb push tests/miniapp/06-tts.lua /miniapp/
```

设备需联网且云端支持文本合成。进入约 1.5 秒后自动请求播报；第一句结束后在结果回调内
请求第二句。重叠请求必须收到 `failed/busy`，不能退出应用或排队播放。
单击再次测试，快速双击取消；取消后不应继续收到该请求回调。
语音唤醒、闹钟抢占和恢复需要单独进行音频竞争联调；本用例的自动流程不覆盖这些场景。
若进入时设备正在对话，应显示 `failed/busy`，对话照常继续。
